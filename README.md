# Instant-Search
Search instantly with your screenshots. When you come across a movie clip while scrolling through short videos, do you ever want to know right away which movie it’s from? When a friend shares a photo of a celebrity but you don’t recognize them, do you want to find out who they are immediately? With this program, you can take a screenshot using a shortcut to instantly access information on your screen. Whether you need to identify an image, understand a line of code, or translate a message, Instant Search can provide you with quick answers and recommend relevant websites to help you dig deeper.

# Install
- Download the project from GitHub.
- Install the required dependencies.
    ```bash
    pip install -r requirements.txt
    ```
- Run the project.
    ```bash
    python main.py
    ```


# Vision
With the development of technologies, how people interact with things needs to be reconsiderred. Here, we want to get rid of the traditional way of searching information in the search box and use the power of LLM to explore new ways of searching information (combining 2D image information).
